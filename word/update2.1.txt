一、确认后的实施原则

本方案基于 update2.txt 中的优先级，并结合用户已确认的四项决策制定。后续 Codex 对照实施前，必须先等待用户明确确认，不得直接进入代码修改。

已确认决策如下：

1. 完整三维 Appleton-Hartree O/X 射线追踪首版接受“数值 Hamiltonian 有限差分”实现。该方案优先保证公式清晰、可验证和可退化到各向同性模型；性能优化放在后续版本。

2. Ray-PE/SSF 双向混合接口首版接受 2.5D 局部截面方案。完整 3D PE/SSF 记录为下一期升级项，不在 update2.1 首轮实现中展开。

3. 新功能默认关闭，保持旧场景数值可复现。推荐默认配置为：
AH3D_ENABLE = False
PE_COUPLING.apply_to_power = False
SCATTER.apply_to_pd = False
ABSORPTION_COMPLEX.enable = False
EXTERNAL_NE_PROVIDER.enable = False

4. 允许新增统一外部电子密度接口 NeProvider，但不实施 U3 同化和 U8 三维随机不规则体。后续外部电子密度分布数据可通过 NeProvider 接入折射率计算。

二、总体排序

update2.1 以“功能升级优先，功能扩展次级”为准则排序。排序不完全等同于 update2.txt 的 P0/P1/P2，而是按依赖关系和功能闭环重排。

第一阶段是接口和正确性底座。该阶段对应 U10，并补充 NeProvider 最小接口。目标是建立公式、代码、字段、测试和报告之间的追踪矩阵，确保后续 O/X、PE/SSF、散射闭环和吸收模块的改动不会破坏旧结果。

第二阶段是完整三维 O/X 射线追踪。该阶段对应 U1，是核心功能升级。目标是用真正的三维 Appleton-Hartree 分支射线替代当前沿各向同性轨迹的 O/X 后处理近似，同时保留旧后处理作为对照模式。

第三阶段是 2D 到 3D 混合传播能力收口。该阶段不是单独的 update2 条目，而是为 Ray-PE/SSF 双向耦合做准备。目标是统一 2D/3D mode 字段、局部坐标、轨迹投影和功率/时延接口。

第四阶段是 Ray-PE/SSF 双向混合接口。该阶段对应 U5。首版采用 2.5D 局部截面，由 3D 射线提供局部传播方向、截面坐标和入射场，由 PE/SSF 返回损耗、角谱和延迟展宽诊断。

第五阶段是散射诊断到 P-D 谱闭环。该阶段对应 U4。目标是把 Born/Rytov/MPS 的 S4、sigma_tau_ms 和 scatter_method 转换为 P-D 谱展宽核，但默认不改变旧 P-D 谱。

第六阶段是复折射率吸收与功率链一致化。该阶段对应 U2。目标是新增碰撞频率和复折射率吸收路径积分，先作为功率链模块接入，后续再与 AH3D 的复折射率统一。

第七阶段是功能扩展。该阶段包括 U6 参数扫描与不确定性、U7 Es 方位敏感性、U9 OTH clutter/Bragg Doppler。它们应在核心功能稳定后实施。U3 和 U8 本轮不实施。

五、阶段 2：完整三维 Appleton-Hartree O/X 射线追踪

目标：
用完整三维 O/X 分支射线追踪替代当前 O/X 后处理近似，同时保留后处理作为诊断对照。

新增或修改文件：
code/models/ray_tracer_ah_3d.py
code/models/point_to_point_ah_3d.py 或扩展 code/models/point_to_point_3d.py
code/main.py
code/config.py
code/tests/_verify_AH3D.py
code/viz/plot_utils.py

核心公式：

Appleton-Hartree 分支折射率使用 X、Y、Z 和 theta 表示：
X = wp^2 / w^2
Y = wH / w
Z = nu / w
theta = arccos((k dot B) / (|k| |B|))

首版可采用无碰撞或弱碰撞实折射率：
n2_AH = f_AH(X, Y, Z, theta, branch)

数值 Hamiltonian 首版可采用：
H(r, k) = |k|^2 - k0^2 * n2_AH(r, k_hat, branch)

射线方程用有限差分求偏导：
dr/ds = partial H / partial k
dk/ds = -partial H / partial r

关键实现要求：

1. ray_tracer_ah_3d.py 应与 ray_tracer_3d.py 保持相似输出字段：
trajectory_3d
geom_path_km
group_path_km
tau_ms
h_reflect_km
x_land_km
y_land_km
azimuth_deflect_deg
beta_deg_tx
az_deg_tx
wave_mode
branch_status

2. group_path_km 仍必须保持 integral(ds / n_group_equiv)。首版若暂用 n_group ~= 1/n_r，应在字段中显式记录：
group_index_model = "cold_plasma_ng_approx"
禁止把几何路程误写为群路径。

3. point_to_point_ah_3d.py 或 find_all_rays_ah_3d 应支持：
wave_mode='O'
wave_mode='X'
wave_mode='both'

4. main.py 中 run_with_OX 应支持配置选择：
OX_MODE = "postproc" 或 "ah3d"
默认仍为 "postproc" 或 AH3D_ENABLE=False，以保持旧结果复现。

5. 若开启 AH3D，应额外导出 modes_OX_ah3d.csv 或在 modes_OX.csv 中写入 ox_solver="ah3d" 字段，避免与旧后处理结果混淆。

正确性验证：

1. fH_MHz = 0 时，O/X 结果应退化到各向同性 RefractiveIndex3D，tau_ms 和 group_path_km 误差应在设定容差内。

2. 在弱磁化、低扰动场景下，AH3D 的 O/X tau 差应与 _apply_OX_split_3d 后处理结果同阶。

3. near-cutoff 或 n2 很小处不得产生非物理负 n2 传播。应使用 branch_status 标记 cutoff、evanescent、invalid_step 等情况。

4. O/X 分支应分别输出独立 y_land_km、h_reflect_km 和 azimuth_deflect_deg。

需要开启 AH3D 的情况举例：

1. 研究高精度 TDOA、相位差或 O/X 到达时间分裂。
2. 研究 O/X 分支反射点、横向偏移和焦散是否不同。
3. 研究磁倾角、磁偏角变化对三维传播路径的影响。
4. 论文中需要声称“完整三维 O/X 射线追踪”，而不是“AH 后处理近似”。

首版 2.5D 技术路线：

1. 从 3D ray 中选择局部耦合段，例如反射区附近或不规则体附近。

2. 使用 local_frame 抽取 Ne(s,u) 局部截面，生成 PE/SSF 输入网格。

3. 用射线 mode 的 Pr_W、传播方向和局部相位曲率构造 PE 初始场。首版可用 Gaussian beam 近似，避免复杂波束重构。

正确性验证：

1. 均匀介质中 PE 传播功率守恒。
2. 弱扰动下 PE 主瓣方向与主射线方向一致。
3. 网格 dx、dz 减半时 pe_loss_dB 和 pe_sigma_tau_ms 收敛。

需要开启 PE_COUPLING.apply_to_power 的情况举例：

1. 研究 bubble 或 Spread-F 引起的实际功率衰落，而不仅是诊断指标。
2. 需要让 P-D 谱反映 PE/SSF 计算出的散射损耗和延迟展宽。
3. 与实测功率-时延谱对比，且射线几何损耗明显不足以解释观测衰落。

待升级项：

完整 3D PE/SSF 不在 update2.1 首轮实施。下一期可升级为 s-u-v 三维波场传播，支持横向散射、方位角扩展和三维能量守恒检查。

十三、实施时必须遵守的正确性约束

1. group_path_km 始终表示 integral(ds/n) 或明确记录的 group index 近似，不得用 geom_path_km 替代。

2. geom_path_km 始终表示 integral(ds)。

4. scatter_coupler 默认只附加诊断，不直接改写 Pr_W。

5. PE/SSF 默认只附加诊断，不直接改写 Pr_W。

6. 新功能默认关闭时，旧 main.py 场景结果应保持可复现。

7. 所有随机或扫描功能必须记录 seed 和参数。
