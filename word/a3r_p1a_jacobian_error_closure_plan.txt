A3R-P1A 变分 Jacobian 误差分项闭环计划
日期：2026-07-16

一、阶段定位

P1A 位于 P1 与 P2 之间。P1 已完成多尺度中心差分参考、逐列误差和 fallback 语义，但冻结 Coleman 算例的仰角列仍超过 1e-3：低射线约 3.69e-3，高射线约 1.74e-2；方位角列已达到阈值。P1A 只定位并修正离散切线不一致，不改变 AH3D 色散关系、搜索域、O/X 语义、P0C 模式集合或验收阈值。

P1A 完成前：

1. p1_acceptance_passed=false；p2_gate=closed。
2. 生产研究结果继续使用中心差分 reference fallback。
3. 不得宣称变分 Jacobian 已验证加速，不得进入 P2 焦散和模式完整性实施。

二、目标与原则

1. 沿主积分器真实接受步逐步检查离散映射，而不是比较不同自适应轨迹。
2. 将总误差唯一归入 RHS、D=0 投影、地面事件或终端落点转换；无法唯一归因时保留 failed，不猜测根因。
3. 使用无量纲状态尺度处理位置、波矢和群时延的量纲差异；中心差分必须扫描步长并识别稳定平台。
4. 先修正已证实失败的最小组件；不提前引入自动微分、新积分器或第二套求解器。
5. 保留非有限、相对误差大于 1e-3、条件数大于 1e10 的中心差分 fallback。

三、冻结诊断算例

1. Coleman Chapman F2 low_ray：beta=35.339808 deg，B=0，各向同性退化。
2. Coleman Chapman F2 high_ray：beta=39.918777 deg，B=0，各向同性退化。
3. 平滑分层单模：远离 cutoff，分别检查仰角和方位角列。
4. TID 3D：远离 cutoff，分别检查 O/X；不得用 O/X 合并结果替代分支检查。
5. near-cutoff：只验证病态识别和 fallback，不纳入 1e-3 良态验收。

每个算例冻结 Provider/config 哈希、频率、分支、发射角、积分 profile、中心差分尺度和终止状态。P0C 高低射线角度和电子密度参数不得为通过 P1A 而调整。

四、实施顺序

P1A-0 接受步审计与可重放记录

1. 在测试/诊断入口记录每个实际接受步的 s、h、步前状态、DOP853 未投影步后状态、投影后状态、RHS、投影修正量和状态标志。
2. 同时记录地面事件所在步的两端状态、插值比例和终端状态。
3. 诊断默认关闭，不改变 main.py/main2.py 输出；记录只服务 P1A，避免生产轨迹内存膨胀。
4. 同一冻结输入重复两次，接受步数、h 序列、终止步和状态哈希必须一致；不一致时先标记 nondeterministic_step_sequence，停止后续归因。

P1A-1 Hamiltonian RHS 方向导数

1. 在相同接受步前投影状态 y_i 上，分别对 beta 列和 az 列检查 J_f(y_i)S_i。
2. 以当前切线 RHS 为被测量，以同一 base_rhs 的尺度化中心方向差分为 reference；扫描至少五个对数步长，选择稳定平台，不固定单一 eps。
3. 分别输出位置、波矢、群时延三个状态块的绝对误差和相对误差，以及全路径最大值、P95 和首次超阈值步。
4. 若 RHS 已在 1e-3 内，禁止改写 Hamiltonian 导数；进入 P1A-2。
5. 若 RHS 失败，优先统一有限差分尺度和状态无量纲化。仍失败时再评估解析偏导；自动微分仅在解析偏导维护成本明显更高且不引入不透明分支导数时考虑。

P1A-2 D=0 投影导数

1. 对每个真实接受步的未投影状态 y_i*，检查投影映射 P(y_i*) 的方向导数 DP S_i*。
2. reference 必须在同一个 y_i* 上对完整 _project_dispersion 映射做尺度化中心差分，不重新积分轨迹。
3. 检查投影后切线满足色散约束切空间条件：|D_y S| 使用 k0^2 和状态尺度归一化后不超过 1e-6。
4. 分别记录 beta/az 列、投影迭代次数、投影修正量和 plus/minus 投影状态；任一扰动投影失败时标记 projection_derivative_invalid 并触发 fallback。
5. 若投影导数失败，只修正投影切线传播；不得通过减少投影次数或放宽 D 残差阈值获取通过。

P1A-3 固定真实接受步的组合离散映射

1. 对 P1A-0 记录的每个 h_i，以同一初态分别传播主状态和微扰状态，要求微扰计算实际前进量与 h_i 一致；若内部拒步导致 h 改变，该样本标记 step_replay_rejected，不混入误差统计。
2. 比较 D(Phi_i)S_i 与“DOP853 接受步 + D=0 投影”完整组合映射的中心差分 reference。
3. 若 P1A-1、P1A-2 单独通过而组合映射失败，检查当前在修改 solver.y 后对 solver.f、步长控制状态和下一步初态的同步；不得直接归因于物理模型。
4. 不调用 SciPy 私有 tableau API；首先复用现有 DOP853 类和实际 h_i。只有公开接口无法实现一致重放且有明确测试保护时，才考虑项目内最小固定步诊断函数，该函数不得成为生产积分器。

P1A-4 地面事件敏感度

1. 仅使用同一个已冻结地面交叉步，不允许 plus/minus 轨迹改变事件括区间。
2. reference 对“步两端状态 -> z=0 事件状态”完整映射做中心差分；被测值使用连续事件面公式 S_event=S-f(g_y S)/(g_y f)，其中 g(y)=z。
3. 输出事件前固定路径参数敏感度、事件时刻修正项、事件后落点敏感度和 |f_z|。
4. 当 |f_z| 接近零时标记 grazing_ground_event，触发 fallback；不得用 1e-3 良态标准验收掠射事件。

P1A-5 终端坐标转换

1. 明确 P2P residual 只使用 x_land_km、y_land_km；群时延、反射高度和接收仰角不属于当前 2x2 落点 Jacobian。
2. 对事件状态到 (x_land,y_land) 的实际转换函数独立做中心差分。当前笛卡尔落点若为恒等选取，应得到精确的前两行；禁止把 Earth-flattening 反射高度修正混入落点 Jacobian。
3. 若后续使用地理坐标，必须显式加入坐标转换 Jacobian 和单位，不在 P1A 预建接口。

P1A-6 最小修正与回归

1. 只修改首个被证明超阈值的组件，并重新执行 P1A-1 至 P1A-5，防止误差转移。
2. 更新 tests/_verify_p2p_jacobian_components.py，保留逐列数值、步长平台、条件数和 fallback 原因。
3. 运行既有 P0C、高低射线、AH3D、P2P Jacobian、真空、single-mode 和 TID 回归。
4. 更新 a3r_p1_implementation_report.txt，记录 root_cause、修正前后误差、运行配置和 P2 gate。

五、验收标准

P1A 仅在以下条件全部满足时通过：

1. Coleman low/high、平滑单模和远离 cutoff 的 TID O/X 良态算例中，beta/az 两列相对误差均不超过 1e-3。
2. 中心差分步长存在稳定平台；积分容差收紧后误差不恶化，并呈收敛或稳定趋势。
3. RHS、投影、事件和终端转换均有独立机器可读诊断，且总误差可由分项结果解释。
4. near-cutoff、条件数大于 1e10、非有限和掠射事件正确触发 fallback，无伪收敛模式。
5. P0C low/high 模式集合、发射角、分支、Provider/config 哈希和正式收敛状态不变。
6. 通过后设置 p1_acceptance_passed=true、p1a_status=passed、p2_gate=open；否则保持 closed。

六、停止条件与风险

1. 若实际接受步不能确定性重放，先保留中心差分 fallback，并将 P1A 标记 blocked_by_discrete_step_replay；不得改用不同积分轨迹伪装分项 reference。
2. 若误差来自 SciPy 自适应接受/拒绝决策的不可微切换，应把该区域定义为数值病态并 fallback；不要求跨步长控制分岔保持光滑。
3. 若解析偏导或自动微分会改变 Appleton-Hartree 根选择、near-cutoff 状态机或 D=0 投影语义，停止该路线，优先保持物理分支正确。
4. P1A 会增加诊断运行时间和内存；诊断只在测试开关下启用，不进入常规 ray fan/P2P 输出。
5. P1A 不处理焦散模式召回、伪弧长延拓、P4 性能优化或 A4 PHaRLAP 外部验证。

七、理论依据

Haselgrove（1955）、Jones and Stephenson（1975）和 Budden（1985）支持 Hamiltonian 射线及其动态灵敏度；Coleman（2011）支持点对点变分落点映射。数值实施必须验证“连续切线方程”和“实际离散积分、约束投影、事件定位组成的离散映射”一致，不能仅凭最终模式接近判定 Jacobian 正确。
