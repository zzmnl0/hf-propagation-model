复杂电离层环境 HF 短波反射/散射混合传播建模报告整理稿

一、算法模型

本项目建立了面向 HF 通信链路与 OTH 雷达链路的三维反射/散射混合传播模型。模型以 IRI-2016 为背景电子密度场，在二维 x-z 背景上叠加 TID、Es、等离子体泡、Spread-F 等复杂扰动，并通过三维射线追踪、点对点求解、功率链和散射诊断形成统一计算流程。

1. 电离层环境建模
采用 IRI-2016 生成背景电子密度 Ne，测试链路为 TX 30N, 120E，RX 距离 1169 km，载频 10 MHz，时间 2020-06-01 12:00 UTC。扰动模型包括：
- TID：支持二维与三维多分量 TID，可描述沿路径与横向传播扰动。
- Es：采用偶发 E 层薄层模型，可产生低高度传播模式。
- 等离子体泡：采用 F 区耗空结构，可改变局部折射率与传播路径。
- Spread-F：通过相位屏和不规则体参数提供散射诊断。
- D 层吸收：通信链路按单程吸收，雷达链路按双程吸收处理。

2. 三维射线与点对点传播模型
核心折射率模型为 RefractiveIndex3D，采用冷等离子体近似计算 n^2，并引入地球曲率展平修正。三维射线状态包含位置和波矢分量，使用 RK4 方法推进，可输出落点、横向偏移 y_land、方位角偏转、反射高度、几何路径和群路径。

点对点传播采用 find_all_rays_3d：先通过射线扇面寻找接近接收点的候选射线，再以发射仰角 beta 和方位角 az 为未知量进行 Newton shooting。P2P_3D 支持 forward 与 central Jacobian，用于平衡计算速度和精度。

3. 群路径、功率与 P-D 谱
本项目将 group_path_km 明确定义为冷等离子体群路径积分 P' = integral(ds/n)，群延迟 tau_ms = P'/c。geom_path_km 仅表示几何轨迹长度，不直接用于群延迟。

通信功率采用自由空间传播损耗、吸收修正和聚焦/散焦因子。雷达功率链采用双程传播与雷达方程。hybrid_model 进一步生成功率-时延谱 P-D spectrum，并识别主传播模式。

4. O/X 模式与散射诊断
O/X 模式采用 Appleton-Hartree 后处理估计磁离子分裂，输出 O 模、X 模群延迟差和群路径差。当前报告中的 O/X 为沿三维各向同性轨迹的后处理结果，完整 3D AH Hamiltonian 射线追踪仍属于后续升级项。

散射模块采用 Born/Rytov/MPS 方法选择机制：弱散射进入 Born，中等散射进入 Rytov，强散射进入 MPS_required 诊断。默认情况下散射诊断不直接改写 Pr_W，以保持主传播链稳定。

二、计算结果与分析

1. 基准场景
基准 F 层主模为 1F_low：
- tau = 4.225 ms
- group_path = 1266.8 km
- h_reflect = 229.2 km
- Pr = -84.50 dBW

该结果给出了 1169 km、10 MHz 链路下的稳定 F 层折返传播基准。group_path 大于地面距离，是因为射线折返路径和 n<1 的冷等离子体修正共同作用。

2. TID 场景
TID 主模仍为 1F_low：
- tau = 4.229 ms
- group_path = 1267.8 km
- Pr = -84.51 dBW
- 相对基准：时延增加 3.29 us，群路径增加 0.987 km，功率变化约 -0.007 dB

说明当前 TID 参数下主模类型未改变，但已产生可量化的微秒级时延扰动和路径扰动。对于 TDOA 定位、相位敏感链路和长期监测，微小群延迟变化仍具有意义。

3. Es 场景
Es 场景出现两个模式，主模切换为低高度 Es 模：
- Es 模 tau = 3.941 ms
- group_path = 1181.5 km
- h_reflect = 107.7 km
- Pr = -83.90 dBW
- 相对基准：时延减少 284.44 us，群路径减少 85.28 km，功率提高约 0.61 dB

说明 Es 薄层能够显著改变传播模式，将 F 层折返转换为低高度快速路径，是所有扰动中对主模结构影响最明显的因素之一。

4. 等离子体泡与综合扰动
Bubble 场景主模仍为 1F_low：
- tau = 4.231 ms
- group_path = 1268.3 km
- h_reflect = 230.7 km
- Pr = -84.51 dBW
- 相对基准：时延增加 5.05 us，群路径增加 1.51 km

综合扰动场景中主模为 Es：
- tau = 3.942 ms
- group_path = 1181.7 km
- h_reflect = 108.4 km
- Pr = -83.90 dBW

说明在多扰动叠加条件下，Es 对主模选择具有主导作用；TID 和 bubble 更多表现为 F 层路径的细微扰动。

5. O/X 分裂结果
O/X 场景得到两个磁离子模式：
- O 模 tau = 4.303 ms，group_path = 1290.1 km，Pr = -84.66 dBW
- X 模 tau = 4.313 ms，group_path = 1293.2 km，Pr = -84.68 dBW
- X 模相对 O 模晚约 10.40 us，群路径差约 3.12 km

结果说明 10 MHz 链路上 O/X 分裂虽未改变传播模式类型，但产生了可解析的群延迟差。对高精度测距、TDOA、雷达回波解释和极化传播分析，该差异不应忽略。

6. 雷达与三维流管雷达
普通雷达场景沿基准路径计算双程雷达功率，主模功率约 -210.56 dBW。

三维流管雷达扫描得到 6 条相邻模式，仰角范围 26.5-29.0 deg：
- 单程 tau = 3.998-4.481 ms
- 双程 tau = 7.997-8.962 ms
- group_path = 1198.7-1343.4 km
- Pr = -149.73 至 -149.66 dBW
- F_focus_3d 随仰角从约 0.60 增至 0.67
- A_tube_km2 从约 765 减至 493

说明雷达回波谱不是单一模式点，而是由相邻射线管、双程传播损耗、流管截面积和聚焦/散焦共同塑造的功率-时延分布。

7. Spread-F 与散射诊断
Spread-F 场景主模接近 TID 场景：
- tau = 4.229 ms
- group_path = 1267.8 km
- Pr = -84.51 dBW

散射诊断显示，基准、TID、bubble、O/X、radar、Spread-F 多数场景进入 MPS_required；Es 场景为 Born；综合扰动场景为 Rytov。当前默认设置下散射诊断不直接改写主功率，因此功率结论主要来自射线路径、吸收和链路几何。

三、创新点

1. 从二维主传播面扩展到三维传播空间
模型不再只给出 x-z 平面内的射线路径，而是能够计算 y 向横向偏移、方位角偏转和三维点对点射线。这使 TID 横向结构、三维 bubble、流管雷达扫描等问题具备直接建模能力。

2. 将反射传播、散射诊断和功率链统一到同一流程
模型同时输出 tau_ms、group_path_km、h_reflect_km、Pr_dBW、P-D spectrum、scatter_method、sigma_phi_sq 等参数，使通信链路预算、雷达回波分析和复杂电离层扰动诊断能够在同一框架下比较。

3. 明确修正群路径物理定义
将 group_path_km 统一为 integral(ds/n)，并用 tau = P'/c 计算群延迟，避免将几何路径误作为群路径。这一修正提高了时延、P-D 谱和 O/X 分裂解释的一致性。

4. 形成多场景可复现实验体系
当前已覆盖基准、TID、Es、bubble、综合扰动、O/X、雷达、Spread-F、三维流管雷达等 9 类场景，并配套 modes_*.csv、pd_*.png、ray_fan_*.png、ray_deflect_tid.png 等输出。验证脚本覆盖 group_path、O/X、3D 吸收、P2P Jacobian、散射耦合和 Phase 5-7 功能，主要验证均为 0 fail(s) 或 PASSED。

5. 保留稳定默认行为与后续升级接口
Born/Rytov/MPS 散射默认作为诊断，不直接改写主功率；O/X 当前为后处理，不夸大为完整三维 AH 射线追踪。配置中已预留 AH3D、PE coupling、scatter-to-PD、complex absorption、external Ne provider 等升级开关，便于后续逐步增强而不破坏现有结果可复现性。
