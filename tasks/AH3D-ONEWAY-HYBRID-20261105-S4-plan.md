## 1. 路线分离

新路线的实现位于 `ray_wave_oneway/`。入口、案例参数和输出目录独立，输出统一位于 `output2/ray_wave_oneway/`。原 `main.py`、全局 `config.py`、`models/unified_hybrid_pipeline.py` 继续承担原 AH 路线。新路线通过显式适配器调用已有 AH 数值内核。

此前三个 `models/` 实验模块保留兼容导出，科学实现只有新目录中的一份。S1/S2/S3 历史产物保留。迁移后的回归单独写入 `output2/ray_wave_oneway/s4/isolation/`。

分离验收覆盖依赖方向、新计算前后原配置一致、原磁化 AH 轨迹和群时延一致，以及三个阶段的回归。

数值设置同样归新路线管理。新模型显式给定等离子体系数、空间差分与积分配置名称，适配器采用 `ONEWAY_L2_SETTINGS`，消除对原 `UPDATE2` 默认值的隐式读取。当前新路线采用独立 L2，容差为 `rtol=1e-10`、位置绝对容差 `1e-8 km`、归一波矢绝对容差 `1e-12`，初始／最大步长为 `0.002/0.5 km`。空间差分基步长为 `0.03125 km`，其余尺度与稳定性设置由 `ONEWAY_AH_FD_SETTINGS` 显式提供。

验证在独立测试进程内改变原 AH 数值设置，确认新路线的模型设置、实际外段与结果相同。原 AH 核心继续复用。均匀外段改用新适配器后重新运行 S2/S3 及 S4a 正常入口。

## 2. S4a 独立入口与散射观测量

先交付可运行的受控磁化案例，从同一固定物理源和 RX 模板计算跨频散射复响应。每个频率重新建立介质、端口、局部散射算符及 AH 外段，保存背景与完整窗口响应，保持 `S`、`S0` 和窗口替换含义一致。

慢时间采用确定性不规则体的实际平移，在各时刻重新求解。产品包括复频响、固定 RX 功率、频率相位导数时延、慢时间相位导数频移，以及明确采样窗口和分辨率的功率－时延产品。默认参数集中在新路线内部。所有结果标明受控案例、源功率归一和 RX 模板定义。

必要验证覆盖零扰动背景恢复、相位差分收敛、平移与跨谱相位关系、慢时间频移符号、固定 RX 的相干投影、延迟变换的能量归一，以及独立正常入口产生可读取的结果。

首批沿用 S3 的 Ne、B、层厚和周期，跨频保持物理密度相同。频率采用 9.5–10.5 MHz 的九点采样，中心频率另取 ±1 kHz 与 ±0.5 kHz 核对局部群时延。慢时间在中心频率取九点、间隔 0.25 s，平移速度取 `Lu/8 s` 与 `Lv/10 s`。

统一采用 `exp(-i omega t)`，群时延为 `d arg(H)/d omega`，物理频移为 `-d arg(H)/dt/(2 pi)`。平移算符的独立核对使用 `DeltaS_qk(t) = exp[-i (kt_q-kt_k) dot v t] DeltaS_qk(0)`。有限带宽脉冲的功率－时延产品同时报告分辨率与离散无模糊窗，低于分辨率的展宽标记 `UNRESOLVED`。

延迟变换采用 `h_B(tau) = df sum[W_j H(f_j) exp(-i 2 pi (f_j-f0) tau)]`，慢时间物理频移变换采用正指数。以纯正延迟和纯物理频移响应分别核对变换符号。

## 3. S4b 非均匀 AH 几何与作用量适配

以独立适配器接收实际 ECEF 位置和波矢，复用原 AH RHS 和色散规则。新增接收平面事件、传播方向选择、作用量积分、群时延和终点状态。增强状态向旧核心传递原有七维分量。

使用均匀介质解析解和非均匀平层反射控制验证命中、转向、守恒横向波矢、作用量和群时延。反射控制采用与核心独立的数值积分参照。此包输出射线几何及作用量，完整相干输运由下一包补齐。

## 4. 后续滚动包

S4c 依据前两包结果补非均匀背景中的复场输运。优先利用平层背景的平移对称性，以守恒切向波矢和法向功率归一建立可核验控制，加入反射相位与固定 RX 重建。窗口交互次数与真实几何一致。

进入毫秒级长程响应前，先处理主值相位差与离散频率采样的时延歧义，采用参考相位去旋或相应解缠，并以毫秒级纯延迟控制核对。现有短程控制继续按其有限带宽和无模糊范围解释。

随后扩展至已有参数化 Ne、O/X 分支和完整功率产品。一般三维背景需要束映射、偏振输运和焦散处理，其细案在实际接口与控制结果完成后滚动制定。

## 5. 执行与验收
