## 3. 共同介质与单位约定

### 3.1 快照

以当前 AH 模型为源，显式携带以下信息。

| 信息 | 规范 |
|---|---|
| r_ecef_km、coordinate_model、地球参数 | 沿用当前 ECEF AH 及 Provider 定义 |
| medium_time_s 与背景日期 | 保存 Provider 所用相对时刻及其日期上下文 |
| frequency_hz | 内核采用 Hz，调用入口可接受当前 MHz 并集中换算 |
| Ne_m3、B_ecef_T、collision_s | 同一点、同一时刻取得的实际介质值 |
| plasma_coefficient | 直接读取该 AH 模型实际采用值，单位 Hz² m³ |
| epsilon_ecef | 由上述量生成的冷等离子体张量 |
| 基底与来源标识 | 保存局部基底、Provider 标识和参数摘要 |

普通物理模式下，当前 AH 默认系数为 80.61638587963631 Hz² m³。兼容模式显式采用的其他系数随实际模型传入。电子密度保持 Provider 的实际数值。

Ne 和 B 继续使用现有 Provider 接口。碰撞采样复用当前 AH 的实际标量／函数配置。新增接口的时间参数按显式值传递，验证中至少使用一个非零时刻。

### 3.2 位置、波矢和场

- Provider 接口使用 ECEF km，局部内核使用 m。
- AH 物理波矢由 rad/km 转换为 rad/m 时乘 10^-3，输出恢复时采用逆变换。
- B 使用 T，碰撞频率使用 s^-1，Ne 使用 m^-3。
- E 使用 V/m，H 使用 A/m。
- 固定时间约定 exp(-iωt)，空间相位采用 exp(+ik·r)。
- 局部基底按 (e_s,e_u,e_v) 的列向量排列，满足右手系，法向分量与横向分量的排列写入数据。

已有张量函数的可选系数必须保持旧调用数值与输入语义。新接口显式传入模型系数，标识物理模式与兼容模式。S1 对此增加一个小型兼容检查。

## 4. 功率与偏振端口

### 4.1 端口适用域

两侧均采用均匀、无碰撞介质，各有两个可传播电磁模态，法向能流非零。磁化 O/X 端口选择非简并的简单根，近截止、倏逝、纵向消元奇异等情况返回明确状态。

真空和 B=0 控制例采用固定 TE/TM 或横向偏振基底，并保存简并信息。固定磁场规范例采用传播根与偏振共同识别模式。

### 4.2 有限归一面积

平面波端口规定参考胞面积 A_ref=1 m²。以法向 Poynting 通量归一

P = A_ref × 0.5 Re[(E×H*)·n]。

每个端口模态归一到 1 W。模态的入／出方向由相对于该侧外法向的能流确定。相应振幅系数采用 sqrt(W) 的功率波规范，并保存其物理 E/H 基底。通量密度 W/m² 与总端口功率 W 分别记录。

无耗、可分离的外部模态按通量内积正交归一。输入／输出模式顺序和参考面统一后，单个通道系数的模平方给出对应功率。

### 4.3 相位与偏振规范

每个端口保存完整复 E/H 基底和相位原点。S 与 S0 复用同一组外部端口基底。相位固定可采用明确的参考分量及相位规则，或者携带精确基底变换关系。角谱投影与复场重建使用同一规范。

验证至少包含一次端口基底重相位检查，系数随基底进行相应变换后，重建物理 E/H 保持一致。这项检查与有限束角谱衔接直接相关，纳入三组验收统一执行。

磁化偏振独立对照使用 k∥B 的圆偏振解析解，显式记录固定坐标下的 (e_u±i e_v)/sqrt(2)、电子电荷、B 方向及传播方向。检验偏振和对应色散根，并检查 B 反向的变化。名称 R/L 随所声明的观察方向解释，解析期望独立于被测张量矩阵生成。

## 5. 均匀薄层全波参考

### 5.1 求解问题

外部背景、内部均匀层和两界面均显式给定。针对固定 (k_u,k_v) 使用现有 4×4 Berreman 算子，求两前向和两后向场分量，匹配两界面切向 E/H 连续条件。

同时包含两传播方向的边界值求解给出反射、透射及磁化偏振转换。实现使用微型复矩阵求解和所需相位传播。控制例选择薄层、适度介质对比及温和耗散，保证直接边界匹配处于良好条件范围。

本阶段实际角谱参数至少包含一个非零 k_t 的倾斜传播案例。后续有限束由多个 k_t 调用构成，S1 的单 k_t 矩阵相应为块对角规范问题。

### 5.2 四端口约定

输入向量 a 由左侧向右传播的两个模态与右侧向左传播的两个模态组成。输出 b 由左侧出射的两个模态与右侧出射的两个模态组成。

b = S a。

S 为 4×4 复矩阵。单侧照射时取对应的 2×2 R/T 子块。左右端口坐标、法向、波矢和模态顺序写入结果，矩阵运算以该规范为准。

### 5.3 背景及窗口替换

调用者显式指定 S0 使用的背景层介质和界面配置，层厚、参考面与左右外部端口基底与 S 相同。S0 包含背景传播相位。四端口形式下，同介质透明控制例的透射位于跨侧子块，反射子块为零。若左右外部背景不同，S0 可包含相应界面反射，并按指定配置求解。

推荐后续以完整 S 替换该段 AH 传播。ΔS=S−S0 用于对照和诊断。背景相位和直达复场在完整链路中按该替换关系记账。

### 5.4 独立吸收与功率预算

无耗案例检查功率归一基底上的 S†S=I。有耗薄层检查 S†S≤I，考虑复模态相干输入。

独立吸收采用层内实际电场和张量耗散部分

epsilon_loss = (epsilon−epsilon†)/(2i)，

P_abs = A_ref × ω epsilon_0 / 2 × integral[E† epsilon_loss E ds]。

该定义包含完整磁化张量的耗散信息。积分以足够精度的小规模求积完成，并进行一次加密核查。R/T 输出功率与该体耗散共同构成功率闭合残差。
