## 1. 路线分离的实际结果

用户要求“与原 AH 区分路线，保证分离”。新科学实现迁入 `ray_wave_oneway/`，其中 `local_wave.py`、`propagation.py` 和 `periodic.py` 对应已经接受的 S1/S2/S3 实现。原来三个实验模块保留薄兼容导出，调用对象与新实现相同。

原 `main.py`、全局 `config.py`、`models/unified_hybrid_pipeline.py` 和 AH 内核在本轮分离中沿用原有实现。新路线的入口为 `python -m ray_wave_oneway`，案例参数位于 `ray_wave_oneway/config.py`，结果位于 `output2/ray_wave_oneway/`。

隔离测试验证旧入口导入时没有加载新包，新包求解前后原配置逐项一致，原磁化 AH 射线的位置、波矢和群时延逐值相同。迁移后的 S1/S2/S3 分别通过 100/35/33 项检查，独立审查接受此隔离包。

S1 已按修复后的默认路径直接重跑。该批 S2/S3 实际通过 Python 加载验证模块、将 `OUT` 指向隔离目录后调用 `main()` 运行。其产物 manifest 中普通脚本命令是当前可复现入口。三个验证器的默认输出随后均改为 `output2/ray_wave_oneway/s4/isolation/{s1,s2,s3}/`。

数值配置隔离后，S2/S3 又以普通脚本命令完整重跑，分别通过 35/35、33/33。新路线的 L2 积分和空间差分参数来自独立配置，正常入口 manifest 保存其实际数值。测试改变原 AH 数值设置时，原 AH 仍读取自己的配置，新路线的模型及实际射线结果保持逐值一致。

历史 `output2/oneway_hybrid_20261105/` 产物保留。共享 Maxwell 张量在 S1 已有可选 `plasma_coefficient` 参数，省略参数时保留原有默认语义，本轮分离未继续修改它。

## 2. S4a 散射观测产品

以已接受的磁化介质、两横向确定性密度结构和固定物理 E/H 收发模板为起点。每个频率重新建立物理介质快照、端口、散射矩阵和 AH 外段。慢时间由不规则体密度平移后重新求解。

案例保存投影后的实际入射功率、固定 RX 功率及其比值。采用 `exp(-i omega t)`，局部群时延为 `d arg(H)/d omega`，物理频移为 `-d arg(H)/dt/(2 pi)`。延迟变换使用负指数，慢时间物理频移变换使用正指数。

独立正常入口已完成 13 个实际频点，其中 9 点覆盖 9.5–10.5 MHz，4 点用于中心频率相位差分。中心频率另完成 9 个慢时间切片的真实密度平移重解，间隔 0.25 s。

| 指标 | 实测 |
|---|---|
| ±1 kHz 差分群时延 | 0.9649101128 μs |
| ±0.5 kHz 差分群时延 | 0.9649101296 μs |
| u 向移动侧带物理频移 | 0.12500049 Hz，理论值 0.125 Hz |
| v 向移动侧带物理频移 | 0.10000009 Hz，理论值 0.100 Hz |
| 相干 RX 总场局部频移 | -0.00242925 Hz |
| 中心频率 RX/Pin | 0.9974901143 |
| 跨频最大功率预算残差 | 约 1.8e-15 W |
| 延迟 DFT 网格间距 | 0.888889 μs |
| 带宽对应时延分辨率 | 约 1 μs |
| 离散延迟无模糊周期 | 8 μs |
| 慢时间频移 DFT 网格间距 | 0.444444 Hz |

主场频移和单个移动侧带频移各有定义，分开保存。散射时延展宽标为 `UNRESOLVED`，小于频移 DFT 网格间距的移动侧带频移由相位导数估计。

`observables.npz` 保存复数 `frequency_H/H0`、`slow_H/H0`，完整 `frequency_S/S0`、`slow_S/S0`，外段相位、源与 RX 系数以及固定物理 E/H 模板。频率数组含 13 个点，慢时间数组含 9 个点，完整窗口矩阵每点为 100×100。源模板投影的实际 `Pin`、`Prx` 和 `Prx/Pin` 逐频记录。

观测验证器通过 27/27 项检查，覆盖解析正延迟与正物理频移、真实平移侧带、完整 S 重放、归一和分辨率。验证器读取现有产物并计算额外解析控制，完整物理解算通过独立入口执行。

配置隔离后已通过独立入口完整重算，Reviewer 对该新批次再次运行验证器，27/27。独立重解一个真实移动时刻与零扰动结构，矩阵误差均为零。完整 S／S0 及物理 E/H 投影重放误差为零。显式延迟／物理频移变换和保存结果的最大差分别约 `4.16e-17`、`8.61e-19`。独立改变原 FD、默认 profile 并删除原 L2 配置后，完整单频结果逐值相同。S4a 已获独立 ACCEPT。

## 3. S4b 非均匀 AH 几何与作用量

新增 `ray_wave_oneway/ah_adapter.py`，从实际 ECEF 位置和波矢续接 AH。适配器在独立包装内给原七维状态追加作用量，向原 AH 核心传递七维状态，逐步投影色散壳，并以稠密插值定位指定方向的接收平面穿越。

受控非均匀背景采用 `B=0` 和 `n²(z)=0.8-0.02 z`，其中 `z` 以 km 计，相对法向 45° 入射。射线转向后首次下行回到发射平面。独立积分给出 80 km 横向位移、0.421929 ms 群时延和 14138.973636 rad 作用量。

Worker 首批通过 22/22 项检查。均匀磁化介质与原 AH 末态相差约 `9.2e-13 km`，作用量解析误差约 `3.5e-11 rad`。非均匀反射控制的横向位移、群时延和作用量误差分别约 `1.3e-11 km`、`6.6e-17 s` 和 `2.3e-9 rad`。另完成介质时刻、色散壳输入、步长减半及与原 AH 非均匀路径的核对。

独立审查发现，完整积分步的试探点可能越过目标平面并进入 Provider 域外，使合法接收点求解失败。修复在每个阶段核对 Provider 和差分域，从上一接受状态携带已有群时延与作用量缩步重试。合法目标可命中，域外目标明确失败并保留原因。有界域反例自动重试两次后命中，与小步长参考的群时延、作用量差分别约 `2.4e-18 s`、`1.2e-10 rad`。

数值配置修复后，适配器采用新路线的 `ONEWAY_L2_SETTINGS`，模型显式采用 `ONEWAY_AH_FD_SETTINGS`。在测试进程内改变原 AH 的 L2 数值设置、空间差分步长和默认 profile 后重新建模和追踪，位置、波矢、群时延和作用量数组逐值相同。当前完整回归为 29/29，适配器支持独立 L2，对其他 profile 给出明确错误。

Reviewer 独立重跑最终 29/29，并以实际有界网格 Provider 核对自动缩步、零域外 Ne 查询及域外目标的明确失败。S4b 已获独立 ACCEPT。

该接口交付射线几何、群时延和作用量。非均匀复场接续仍需要反射相位、振幅、偏振输运与实际 RX 场重建。
