[Haselgrove 方程核验]
标准形式 (Jones & Stephenson 1975, Cartesian, 弧长参数化):
  dx_i/ds = k_i / |k|        (方向余弦)
  dk_i/ds = (k_0^2 / 2|k|) * dn^2_eff/dx_i

代码实现 (haselgrove_3d_deriv, ray_tracer_3d.py L373):
  dx/dP = kx/kmag            ✓  (kmag = |k| = n*k0)
  dy/dP = ky/kmag            ✓
  dz/dP = kz/kmag            ✓
  dkx/dP = (k0^2/(2*kmag)) * dn2_dx   ✓
  dky/dP = (k0^2/(2*kmag)) * dn2_dy   ✓
  dkz/dP = (k0^2/(2*kmag)) * dn2_dz   ✓
  |dr/dP|^2 = (kx^2+ky^2+kz^2)/kmag^2 = 1  => P = 弧长 ∫ds  ✓

[地球展平核验]
Jones (1975), PHaRLAP Cervera & Harris (2014):
  z_phys = z_cart - (x^2+y^2)/(2*R_E)          ✓  [ray_tracer_3d.py L306]

  有效范围: 水平距离 < 1500 km (一阶抛物近似)  ✓

[在壳条件 (on-shell) 归一化]

代码: _renorm_k() 在 trace_single_ray_3d() 每步调用  [ray_tracer_3d.py L503]
作用: 防止数值积分累积的偏离 Hamilton-Jacobi 约束  ✓

[自适应步长]

n^2 < 0.20  -> 0.4*ds_nom
其余       -> ds_nom

[TID 三维扰动]
Hooke (1968) / Koval et al. (2018) 公式:

[严重问题: 群延迟积分公式错误]
标准公式 (Davies 1990 "Ionospheric Radio", §3.3):
  群路径 P' = integral(n_g * ds) = integral(ds/n)  (冷等离子体 n_g = 1/n)
  群延迟 tau = P' / c = integral(ds / (n*c))

代码实现 (trace_single_ray_3d L504):
  group_path += ds        <- 累积弧长 integral(ds)，非群路径
  tau_ms = group_path / C_KMS  <- 等效于 integral(ds)/c

[BUG] 代码计算的是 tau_geom = integral(ds)/c (几何路径时延)，
      而非正确的群时延 tau = integral(ds/(n*c))。
      由于电离层中 n < 1 (通常 0.7~0.99)，1/n > 1，
      真实群时延比几何时延大约 5~15%。

      估算误差: 1169km链路，典型几何弧长~1270km，平均n~0.9
               tau_code    = 1270/299.792 ≈ 4.24 ms
               tau_correct = 1270/(0.9*299.792) ≈ 4.71 ms
               误差 Δtau ≈ +0.47 ms (+11%)

      修复方案: 在 trace_single_ray_3d 中额外累积
               group_path_true += ds / n_current
               n_current = sqrt(n3d.n2(x, y, z)) (已在n2_here中可得)
               然后 tau_ms = group_path_true / C_KMS

[Appleton-Hartree 磁离子折射率]
Budden (1961) "The Propagation of Radio Waves" Eq. 4.13:
  n^2_{O,X} = 1 - X / (1 - Y_T^2/[2(1-X)] -/+ disc)
  disc = sqrt(Y_T^4/[4(1-X)^2] + Y_L^2)
  X = fp^2/f^2, Y_T = (fc/f)*sin(theta), Y_L = (fc/f)*cos(theta)
  O模: - 号;  X模: + 号

代码 (RefractiveIndexAH.n_batch, ray_tracer.py L344):
  X = (K_FP^2)*Ne / (freq_MHz*1e6)^2                    ✓
  half = YT^2 / (2*(1-X))                               ✓
  disc = sqrt(max(YT^4/(4*(1-X)^2) + YL^2, 0))         ✓
  O: denom = 1 - half - disc                            ✓  (Budden O-mode sign)
  X: denom = 1 + half + disc ...

  [WARN] 代码实际: denom_O = 1 - half - disc
                   denom_X = 1 - half + disc
  验证 Budden (1961) Eq.4.13: n^2 = 1 - X/(1 - Y^2/(2U) +/- disc)
       O模 (-号): 分母 = 1 - Y^2/(2U) - disc ✓
       X模 (+号): 分母 = 1 - Y^2/(2U) + disc ✓
  代码符合 Budden 约定  ✓

[磁场角度近似]
代码使用固定角度近似: theta = pi/2 - dip_deg (F层顶点处射线近似垂直)
  code: alpha = pi/2 - self.dip  (ray_tracer.py L360)
  Y_L = Y*cos(alpha) = Y*sin(dip)  [纵向分量]
  Y_T = Y*sin(alpha) = Y*cos(dip)  [横向分量]

[WARN] 此近似仅在射线近垂直反射点处精确，沿整条轨迹的实际

[算法基础]
参考: Cervera & Harris (2014) JGR，两参数 Newton 射击法

[牛顿迭代核验]
Jacobian (2x2 单侧差分, d_beta=0.05deg, d_az=0.10deg):
  J11=dx/d(beta), J12=dx/d(az), J21=dy/d(beta), J22=dy/d(az)
  F = [x_rx - x_c, y_rx - y_c]
  delta = J^{-1} * F

代码 (_shoot_3d, point_to_point_3d.py L61):
  ray_c  = 中心点射线 (当前参数)
  ray_bh = beta+d_beta 射线
  ray_ah = az+d_az 射线
  dx_db = (ray_bh['x_land'] - ray_c['x_land']) / d_beta    (单侧)

[WARN] 使用单侧 Jacobian (前向差分，3射线/迭代) 而非中心差分 (5射线/迭代)。
        单侧精度 O(h)，中心差分 O(h^2)，但对 HF P2P 应用足够用。
        PHaRLAP 使用中心差分获得更稳健的收敛，特别是在色散强时。

[收敛判断]
  err = ||F|| = sqrt((x_rx-x_c)^2 + (y_rx-y_c)^2) < tol_km  ✓

  beta 被 clip 到 [2, 88] 度以防不物理解  ✓
